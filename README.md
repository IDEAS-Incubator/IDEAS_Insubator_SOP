# IDEAS Incubator SOPs

This repository contains the standard operating procedures (SOPs) for all engineers working at IDEAS Incubator.

## Engineering SOP

1. **Plan before coding**
   - Confirm requirements, scope, and acceptance criteria.
   - Break work into small, reviewable tasks.
2. **Use branch-based development**
   - Create a feature/fix branch for each issue.
   - Keep commits focused and descriptive.
3. **Follow implementation standards**
   - Prefer simple, maintainable solutions.
   - Reuse existing patterns and dependencies.
   - Add or update documentation when behavior changes.
4. **Validate quality**
   - Run relevant tests and linters before opening a pull request.
   - Address failing checks before merge.
5. **Code review and merge**
   - Open a pull request with clear summary and impact.
   - Resolve reviewer feedback promptly.
   - Merge only after approvals and successful CI.

## Management SOP

1. **Prioritization and planning**
   - Maintain a clear backlog of engineering tasks.
   - Prioritize work by customer impact, urgency, and effort.
2. **Communication cadence**
   - Share weekly goals and delivery status.
   - Escalate blockers early with owner and next action.
3. **Execution tracking**
   - Track issue ownership, deadlines, and progress.
   - Ensure decisions and action items are documented.
4. **Release readiness**
   - Confirm scope, test coverage, and rollback considerations.
   - Coordinate release timing with stakeholders.
5. **Continuous improvement**
   - Run retrospectives after major deliveries/incidents.
   - Convert lessons learned into process updates.
